# DroidDeck 0.4.1 — experimental fork release

- Real Proton game launches default to `DXVK_LOG_LEVEL=warn`; the setting remains configurable globally or per game.
- Built-in app updates now use releases from the `sj0404-collab/DroidDecker` fork and are signed with its dedicated release key.
- This APK uses a fork-specific signing identity. It cannot update an APK signed by the official upstream key; do not install it over an official DroidDeck installation.
- This experimental build does not add Mali, Xclipse, or PowerVR support. No Mali device testing or compatibility claim is made.
