# DroidDeck 0.4.0 — portable DXVK diagnostics

- Real game launches now default DXVK logging to warnings and errors, reducing routine log output. The level remains configurable globally or per game (`none`, `error`, `warn`, `info`, or `debug`).
- This experimental build does **not** add Mali/Vortek support. DroidDeck's documented GPU support remains unchanged; no Mali device or gameplay performance has been validated.
