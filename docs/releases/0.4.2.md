# DroidDeck 0.4.2 — Lite Linux runtime option

- Choose Lite or Full for the Linux runtime installed when a game is first launched. New installations default to Lite; existing installations keep their current profile unless changed.
- Lite r1 is about 1.0 GB installed and downloads a 301 MB archive. It keeps runtime dependencies and leaves optional components available on demand. The complete upstream Full runtime remains available as a fallback.
- Lite is an experimental reduced runtime built in GitHub Actions and has not been validated on a physical device. This release does not add Mali, Xclipse, or PowerVR support; no game compatibility claim is made for those GPUs.
- This APK uses the same fork-specific signing key as the previous DroidDecker fork releases. It cannot update an official upstream-signed DroidDeck installation.
